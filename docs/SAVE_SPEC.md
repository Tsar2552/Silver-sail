# ระบบเซฟ 2 ชั้น

| | คลังตัวละคร (Vault) | เซฟเนื้อเรื่อง (Campaign) |
|---|---|---|
| เจ้าของ | ผู้เล่นแต่ละคน | Host (เล่นคนเดียว = ตัวเอง) |
| อยู่ที่ | เบราว์เซอร์ผู้เล่น (`ssail_vault_v1`) + ไฟล์ส่งออก | เบราว์เซอร์ Host (`ssail_campaigns_v1`) + ไฟล์ส่งออก |
| เก็บอะไร | ตัวละคร เลเวล เงิน ของ ประวัติ Act ที่เล่น | act/chapter, flags, roots, สำเนาตัวละครของปาร์ตี้, ล็อกแชต, สแนปช็อต 5 ชุด |

## วงจรตัวละคร
1. **เช็กเอาต์:** เข้าเนื้อเรื่อง/ห้อง = ได้ *สำเนา* (จด `baseRev`) คลังติดล็อกอ่อน "กำลังเล่นห้อง X"
2. **เล่น:** Host แก้สำเนาในเซฟเนื้อเรื่อง (EXP, เงิน, ของ)
3. **เช็กอิน (จบ Act):** Host ส่งสำเนากลับ ผู้เล่นเทียบ `rev`
   - ตรงกัน → ทับ, `rev+1`, บันทึกประวัติ
   - ไม่ตรง (เช่นเล่นสองห้องพร้อมกัน) → เก็บเป็น "สำเนาชนกัน" แยก **ไม่ทำของหาย**
4. ผู้เล่นตอบ `rebase` เพื่อให้ Host ได้ `baseRev` ใหม่สำหรับ Act ต่อไป

## การสำรอง
- Host: สแนปช็อตกลิ้ง 5 ชุด (จบฉาก/จบ Act/กดบันทึก) + ปุ่มส่งออกไฟล์เซฟห้อง
- ผู้เล่นได้ตัวละครกลับทุกครั้งที่จบ Act จึงมีสำเนาของตัวเองแม้ Host หาย
- ผู้เล่นออฟไลน์ตอนจบ Act → Host ดาวน์โหลดไฟล์ตัวละครให้ นำไป "นำเข้า" เอง

## ข้อจำกัด (ไม่มีเซิร์ฟเวอร์)
- ล้างข้อมูลเบราว์เซอร์ = เซฟหาย ต้องส่งออกไฟล์สำรองเอง
- กันโกงไม่ได้ ตั้งอยู่บนความเชื่อใจระหว่างโต๊ะ (GM คนจริงคุมอยู่)
